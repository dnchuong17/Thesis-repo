\chapter{API Specifications}

This appendix provides representative API response structures for the VietFlood system. Use recorded Postman responses or logged API traffic to replace placeholders where available.

\section{Authentication API}

\textbf{Endpoint:} \texttt{POST /auth/sign\_in}

\textbf{Response:}
\begin{lstlisting}[language=JavaScript, caption=Sign In Response, label=lst:signin-response]
{
  "statusCode": 200,
  "message": "Login successful",
  "data": {
    "accessToken": "<JWT_ACCESS_TOKEN>",
    "refreshToken": "<JWT_REFRESH_TOKEN>",
    "user": {
      "id": "<uuid>",
      "email": "<user_email>",
      "role": "citizen"
    }
  }
}
\end{lstlisting}

\section{Report Creation API}

\textbf{Endpoint:} \texttt{POST /reports}

\textbf{Response:}
\begin{lstlisting}[language=JavaScript, caption=Create Report Response, label=lst:create-report-response]
{
  "statusCode": 201,
  "message": "Report created successfully",
  "data": {
    "id": "<report_id>",
    "category": ["flood"],
    "description": "<description>",
    "status": "pending",
    "evidence": [
      {
        "url": "<cloudinary_url>",
        "resourceType": "image"
      }
    ]
  }
}
\end{lstlisting}

\section{Deployment Notes}

\begin{itemize}
    \item Use masked values for secrets in the thesis and replace them with actual values in deployment.
    \item Store credentials in CI/CD secrets or environment configuration, not in source control.
    \item Change default RabbitMQ credentials before production use.
    \item Set JWT secrets as cryptographically secure strings.
\end{itemize}
